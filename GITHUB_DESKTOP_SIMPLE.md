# Upload to GitHub Using GitHub Desktop (Super Simple!)

## Step 1: Download GitHub Desktop

Go to: https://desktop.github.com/

Click "Download for Windows"

Install it (click Next through everything)

---

## Step 2: Sign In with GitHub Account

1. Open GitHub Desktop
2. Click "File" → "Options"
3. Click "Accounts"
4. Click "Sign in"
5. Enter your GitHub username
6. Enter your GitHub password
7. Click "Sign in"

Done! You're signed in.

---

## Step 3: Add Your Project Folder

1. In GitHub Desktop, click "File" (top left)
2. Click "Add Local Repository..."
3. Click "Browse..."
4. Navigate to: `C:\Users\admin\Projects\dnd-movie-generator`
5. Click "Select Folder"
6. Click "Add Repository"

---

## Step 4: Publish to GitHub

1. In GitHub Desktop, top right corner, click "Publish repository"
2. Repository name: `dnd-movie-generator`
3. Description: "D&D Transcript to Movie Generator"
4. Make sure "Public" is checked (very important!)
5. Click "Publish Repository"

**That's it!** Your code is now on GitHub! ✅

---

## Step 5: Verify It Worked

1. Go to: https://github.com/YOUR_USERNAME/dnd-movie-generator
2. You should see all your files
3. Perfect! ✅

---

## Step 6: Deploy to Streamlit Cloud

1. Go to: https://streamlit.io/cloud
2. Click "New app"
3. Repository: `dnd-movie-generator`
4. Branch: `main`
5. Main file path: `streamlit_app.py`
6. Click "Deploy"

**Wait 2-5 minutes...**

You get a live URL! 🎉

---

## That's All!

No terminal commands needed. GitHub Desktop does everything!
