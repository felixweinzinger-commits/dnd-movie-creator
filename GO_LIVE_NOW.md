# 🚀 Deploy to Streamlit Cloud in 25 Minutes

## No More Local Installation Issues!

Your app will be online, accessible from anywhere, no setup needed.

---

## 5 Easy Steps

### Step 1: GitHub Account (5 min)

```
1. Go to: https://github.com
2. Click "Sign up"
3. Create account
```

### Step 2: GitHub Repository (5 min)

```
1. Go to: https://github.com/new
2. Name: dnd-movie-generator
3. Select: Public
4. Create
```

### Step 3: Push Code (5 min)

```bash
cd C:\Users\admin\Projects\dnd-movie-generator
git init
git add .
git commit -m "Initial"
git remote add origin https://github.com/YOUR_USERNAME/dnd-movie-generator.git
git branch -M main
git push -u origin main
```

### Step 4: Streamlit Cloud Account (5 min)

```
1. Go to: https://streamlit.io/cloud
2. Click "Sign up"
3. Use GitHub to sign in
```

### Step 5: Deploy (5 min)

```
1. Click "New app"
2. Select repository: dnd-movie-generator
3. Branch: main
4. File: streamlit_app.py
5. Click "Deploy"
```
